# Risk Register

| Risk | Consequence | Control | Stop or escalation |
| --- | --- | --- | --- |
| Stress sign/unit mismatch | invalid mechanics | source-specific conversion and tests | quarantine source |
| Method heterogeneity | biased shared energy/stress | source-stratified metrics and Huber loss | multi-fidelity model |
| Sparse L2 DFPT | overfitting | preserve records, grouped splits, multi-seed curves | acquire more DFPT |
| No paired L3 labels | non-identifiable magnetoelastic branch | keep weight zero | run validated VASP pairs |
| Constraint penalty in stress | contaminated L3 target | E_p threshold and lambda sensitivity | reject calculation |
| Higher-derivative memory | failed training | sparse response batches and edge budgets | reduce batch/load, not physics |
